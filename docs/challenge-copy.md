## Lens description

TripOptic is a voice-first travel copilot for Spectacles. Speak a destination and dates; Gemini drafts a trip while a glass AR HUD shows stay, transit, food, sights, weather, and packing. Pinch for live Places photos (optional Google key), a Snap street map with walking routes, and a camera pack scan.

## What did you update in your Lens?

Shipped a spatial glass UI (neon capsules, circular destination portal, Ask bar), optional bring-your-own Google Places API (New) key for real listings/photos/reviews, Snap MapModule street maps with walking preview, Wikipedia/Imagen image fallbacks, and Experimental APIs so internet + location work together on device — all on Lens Studio 5.15 / Spectacles 2024, still fully open source with no keys in the repo.
